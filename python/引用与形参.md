# Python 的引用、赋值与函数参数

> 文中的类型标注示例按 Python 3.10+ 书写；如果使用更早版本，需要把 `list[str] | None` 等写法改成 `Optional[list[str]]` 等兼容形式。

## 先记住一句话

Python 中，变量更准确地说是**指向对象的名字**。赋值语句通常只是让名字绑定到一个对象，并不会自动复制对象。

函数调用时，Python 把实参对象绑定给函数内部的形参。这个模型常被称为 **call by sharing（共享对象）**：

- 形参和实参最初可能指向同一个对象；
- 函数内部可以修改这个对象，调用者能看到修改；
- 函数内部如果只是让形参改指向另一个对象，调用者的名字不会跟着改变。

因此，简单地说“Python 是传值”或“Python 是传引用”都不够准确。更准确的说法是：**Python 传递对象，并按赋值语义绑定形参。**

## 一、名字、对象和引用

### 1. 赋值不是复制

```python
numbers = [1, 2]
other = numbers

other.append(3)

print(numbers)       # [1, 2, 3]
print(other)         # [1, 2, 3]
print(numbers is other)  # True
```

`numbers` 和 `other` 是两个名字，但它们指向同一个列表对象。通过任意一个名字修改列表，另一个名字看到的也是修改后的结果。

可以把它想成下面这样：

```text
numbers ─┐
         ├──> [1, 2, 3]
other   ─┘
```

### 2. `==` 和 `is` 不一样

- `==`：比较两个对象的值是否相等；
- `is`：比较两个名字是否指向同一个对象。

```python
left = [1, 2]
right = [1, 2]

print(left == right)  # True：内容相同
print(left is right)  # False：是两个列表对象
```

通常只应该用 `is` 判断单例对象，例如：

```python
value = None
if value is None:
    print("value 没有值")
```

不要用 `is` 比较普通整数、字符串或业务值；值比较应该使用 `==`。

### 3. 重新绑定和修改对象

下面两种操作要分开理解：

```python
items = [1, 2]
alias = items

items.append(3)  # 修改原列表
print(alias)     # [1, 2, 3]

items = [10, 20]  # 让 items 改为指向另一个列表
print(alias)      # [1, 2, 3]
```

`append()` 修改了原对象，所以 `alias` 能看到变化；`items = [10, 20]` 只是修改了 `items` 这个名字的绑定关系，不会改变 `alias`。

### 4. 可变对象和不可变对象

常见的可变对象：

- `list`
- `dict`
- `set`
- `bytearray`

常见的不可变对象：

- `int`
- `float`
- `bool`
- `str`
- `tuple`
- `frozenset`

不可变不是说对象永远不能被“替换”，而是说对象创建后不能原地修改。对不可变对象做运算时，通常会得到新对象，再让原名字指向新对象：

```python
number = 10
alias = number

number += 1

print(number)  # 11
print(alias)   # 10
```

列表则常常会被原地修改：

```python
items = [1]
alias = items

items += [2]

print(items)          # [1, 2]
print(alias)          # [1, 2]
print(items is alias) # True
```

这里不要把 `+=` 当成永远等价于“创建新对象再赋值”。具体行为取决于对象类型；理解对象是否可变比死记运算符更重要。

## 二、什么是形参和实参

### 1. 形参（parameter）

形参是写在函数定义中的名字，用来接收调用者传入的对象：

```python
def greet(name: str) -> None:
    print(f"你好，{name}")
```

这里的 `name` 是形参。

### 2. 实参（argument）

实参是调用函数时实际传入的值或对象：

```python
greet("小明")
```

这里的 `"小明"` 是实参。调用发生时，可以近似理解为函数内部执行了：

```python
name = "小明"
```

当然，真实情况不是把字符串文本复制一份，而是让函数里的 `name` 绑定到传入的字符串对象。

### 3. 修改对象不会等于修改调用者的名字

```python
def append_item(items: list[str]) -> None:
    items.append("new")


def replace_items(items: list[str]) -> None:
    items = ["new"]


values = ["old"]
append_item(values)
print(values)  # ['old', 'new']

replace_items(values)
print(values)  # ['old', 'new']
```

`append_item()` 修改了传入的列表对象；`replace_items()` 只让函数内部的 `items` 指向了一个新列表，调用者的 `values` 仍然指向旧列表。

如果希望调用者拿到新对象，就显式返回它：

```python
def replace_items(items: list[str]) -> list[str]:
    return ["new"]


values = replace_items(["old"])
print(values)  # ['new']
```

## 三、函数参数的常见形式

### 1. 位置参数

按照参数出现的顺序传值：

```python
def introduce(name: str, age: int) -> None:
    print(f"{name}，{age} 岁")


introduce("小明", 18)
```

第一个实参绑定给 `name`，第二个实参绑定给 `age`。

### 2. 关键字参数

明确写出参数名，顺序可以调整：

```python
introduce(age=18, name="小明")
```

关键字参数适合参数较多，或者调用处需要强调每个值含义的场景。

### 3. 默认参数

定义函数时可以给形参设置默认值。调用时不传该参数，就使用默认值：

```python
def connect(host: str, port: int = 80) -> None:
    print(f"连接 {host}:{port}")


connect("example.com")       # 连接 example.com:80
connect("example.com", 443)  # 连接 example.com:443
```

默认值是在执行 `def` 语句时计算一次，而不是每次调用时重新计算。因此，不要把可变对象直接作为默认值。

错误写法：

```python
def add_item_bad(item: str, items: list[str] = []) -> list[str]:
    items.append(item)
    return items


print(add_item_bad("a"))  # ['a']
print(add_item_bad("b"))  # ['a', 'b']，默认列表被共享了
```

推荐写法：

```python
def add_item(item: str, items: list[str] | None = None) -> list[str]:
    if items is None:
        items = []
    items.append(item)
    return items
```

### 4. `*args`：接收任意多个位置参数

函数定义中的 `*args` 会把多余的位置参数收集成一个元组。`args` 只是惯用名称，也可以换成其他名字：

```python
def total(*numbers: int) -> int:
    return sum(numbers)


print(total(1, 2, 3))  # 6
print(total())         # 0
```

调用函数时，单个 `*` 还可以把列表或元组解包成位置参数：

```python
def show_three(first: int, second: int, third: int) -> None:
    print(first, second, third)


values = [1, 2, 3]
show_three(*values)  # 等价于 show_three(1, 2, 3)
```

### 5. `**kwargs`：接收任意多个关键字参数

函数定义中的 `**kwargs` 会把多余的关键字参数收集成一个字典：

```python
def show_options(**options: str) -> None:
    print(options)


show_options(theme="dark", language="zh")
# {'theme': 'dark', 'language': 'zh'}
```

调用函数时，双星号可以把字典解包成关键字参数：

```python
def create_user(name: str, age: int) -> None:
    print(name, age)


user = {"name": "小明", "age": 18}
create_user(**user)  # 等价于 create_user(name="小明", age=18)
```

### 6. `/` 和单独的 `*`

Python 还可以精确限制参数的传递方式：

```python
def configure(host: str, /, port: int = 80, *, timeout: float = 3.0) -> None:
    print(host, port, timeout)
```

这个定义可以这样读：

| 参数位置 | 含义 |
| --- | --- |
| `host` | 只能按位置传入，因为它位于 `/` 左侧 |
| `port` | 位置参数或关键字参数都可以 |
| `timeout` | 只能按关键字传入，因为它位于单独的 `*` 右侧 |

```python
configure("example.com", 443, timeout=5.0)
configure("example.com", port=443)
```

下面两种调用会报 `TypeError`：

```python
configure(host="example.com")  # host 不能用关键字传入
configure("example.com", 443, 5.0)  # timeout 必须用关键字传入
```

### 7. 一个函数同时使用多种参数

```python
def demo(
    required: int,
    optional: int = 0,
    *values: int,
    verbose: bool = False,
    **options: str,
) -> None:
    print(required)
    print(optional)
    print(values)
    print(verbose)
    print(options)


demo(1, 2, 3, 4, verbose=True, theme="dark")
# required -> 1
# optional -> 2
# values -> (3, 4)
# verbose -> True
# options -> {'theme': 'dark'}
```

这里的单独 `*` 没有显式写出来，是因为 `*values` 已经标记了后面的参数只能使用关键字传入。

## 四、浅拷贝和深拷贝

如果不想让两个名字共享同一个容器，可以复制对象。

### 1. 浅拷贝

浅拷贝只复制最外层容器，内部嵌套对象仍然共享：

```python
matrix = [[1, 2], [3, 4]]
shallow = matrix.copy()

shallow.append([5, 6])
print(matrix)   # [[1, 2], [3, 4]]

shallow[0].append(99)
print(matrix)   # [[1, 2, 99], [3, 4]]
```

`matrix` 和 `shallow` 是不同的外层列表，但 `matrix[0]` 和 `shallow[0]` 仍然是同一个内层列表。

### 2. 深拷贝

深拷贝会递归复制嵌套对象：

```python
from copy import deepcopy


matrix = [[1, 2], [3, 4]]
deep = deepcopy(matrix)
deep[0].append(99)

print(matrix)  # [[1, 2], [3, 4]]
```

实际项目中，优先明确需要复制哪一层；不需要时不要无脑使用深拷贝，因为它可能复制大量对象，也可能遇到不能直接复制的资源对象。

## 五、作用域和“引用”容易混淆的地方

### 1. 函数内赋值默认创建局部名字

```python
count = 0


def increase() -> None:
    count += 1


# increase() 会触发 UnboundLocalError
```

因为函数中出现了对 `count` 的赋值，Python 默认把 `count` 视为局部名字；读取它时，局部变量还没有值。

如果确实要修改外层全局名字，可以使用 `global`：

```python
count = 0


def increase() -> None:
    global count
    count += 1
```

更常见、更容易测试的方式是通过参数和返回值传递状态，而不是频繁使用 `global`。

### 2. 闭包中使用 `nonlocal`

`nonlocal` 用来修改外层函数的局部名字：

```python
def make_counter():
    count = 0

    def next_value() -> int:
        nonlocal count
        count += 1
        return count

    return next_value


counter = make_counter()
print(counter())  # 1
print(counter())  # 2
```

`global` 找模块级名字，`nonlocal` 找外层函数作用域中的名字。

## 六、查看函数参数如何绑定

普通使用中不需要手动绑定参数，但调试或写装饰器时，可以用 `inspect.signature()` 查看签名，用 `bind()` 模拟一次调用：

```python
from inspect import signature


def configure(host: str, port: int = 80, *, timeout: float = 3.0) -> None:
    pass


sig = signature(configure)
bound = sig.bind("example.com", timeout=5.0)
bound.apply_defaults()

print(bound.arguments)
# {'host': 'example.com', 'port': 80, 'timeout': 5.0}
```

如果传入的参数无法匹配签名，`bind()` 会抛出 `TypeError`。它能帮助理解“参数名、位置和默认值最终如何组合”。

## 七、快速判断题

遇到引用和参数问题时，可以依次问自己：

1. 这里是修改对象，还是让名字重新绑定？
2. 这个对象是可变的，还是不可变的？
3. 两个名字是值相等（`==`），还是对象相同（`is`）？
4. 这个名字是调用者的名字，还是函数内部的形参？
5. 参数是位置传入，还是关键字传入？
6. 默认值是不是一个会被修改的列表、字典或集合？
7. 我需要的是别名、浅拷贝，还是深拷贝？

## 八、参数语法速查

| 写法 | 含义 |
| --- | --- |
| `def f(x)` | 普通参数，可按位置或关键字传入 |
| `def f(x=1)` | 带默认值的参数 |
| `def f(*args)` | 收集多余的位置参数，结果是元组 |
| `def f(**kwargs)` | 收集多余的关键字参数，结果是字典 |
| `def f(x, /)` | `/` 左侧只能按位置传入 |
| `def f(*, x)` | `*` 右侧只能按关键字传入 |
| `f(*values)` | 调用时解包可迭代对象为位置参数 |
| `f(**values)` | 调用时解包字典为关键字参数 |

最重要的不是背下“传值还是传引用”，而是看清楚：**形参和实参是否暂时指向同一个对象，以及函数内部做的是修改对象还是重新绑定名字。**
